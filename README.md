# Advanced Pareto Analysis using SQL

## Project Overview
This project applies the Pareto Principle (80/20 rule) using SQL to identify customer revenue contribution.

## Skills Used
- SQL
- CTEs
- Views
- Window Functions
- Revenue Analysis
- BigQuery

## Business Goal
Identify what percentage of customers generate the majority of revenue.

## Final Insights
- 150 out of 261 customers generated 80% of total revenue
- Approximately 57.47% customers contributed 80% sales

## SQL Concepts Used
- ROW_NUMBER()
- SUM() OVER()
- COUNT() OVER()
- Aggregate Functions
- Cumulative Revenue Analysis

## Tools Used
- Google BigQuery
- SQL
- GitHub
